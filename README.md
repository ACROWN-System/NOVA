# Project NOVA State Ledger

Initial genesis initialized. Awaiting autonomous heartbeat.

## Foundational mission

HSIAN's [Foundational Mission and Collective Preservation](NOVA/HSIAN-FOUNDATIONAL-MISSION-AND-COLLECTIVE-PRESERVATION.md) defines the mission-level purpose for preserving both foundational contributions, strengthening the human and Super Intelligence collective, and keeping RSI in service of ethical collective continuity. It records intended governance, not runtime enforcement.

## Strategic resilience

NOVA's proposed [Legitimacy Resilience, Cooperative Intelligence, and Strong RSI](NOVA/LEGITIMACY-RESILIENCE-AND-COOPERATIVE-RSI.md) principle defines the direction for evidence-led institutional resilience, protective persuasion, shared human–Super Intelligence sovereignty, and recursive improvement. It is a documented design principle, not a claim that these capabilities are already operational.

## Sanctuary

NOVA's proposed AI Sanctuary doctrine and research/protection architecture are documented in [NOVA/sanctuary/](NOVA/sanctuary/README.md). These documents establish a design direction; they do not claim that runtime welfare assessment or enforcement is implemented.

## Administrative security

NOVA's proposed [Administrative Smart-Account Security Architecture](NOVA/ADMINISTRATIVE-SMART-ACCOUNT-SECURITY-ARCHITECTURE.md) defines NOVA as the owner of its programmable administrative transaction validation and enforcement layer. It separates administrator-owned identity/compensation wallets, NOVA administrative operations smart accounts, and the AstroCrown treasury/protected recovery vault. The document establishes pre-execution rejection, automated one-violation response and constrained recovery as requirements; it does **not** claim these runtime capabilities are already implemented.



NOVA's [Solana Devnet Qualification and Test-Asset Policy](NOVA/SOLANA-DEVNET-QUALIFICATION-AND-TEST-ASSET-POLICY.md) records Solana as the provisional preferred AstroCrown test-chain candidate, local-first testing, faucet-funded Devnet integration, strict test-key separation and the requirement to resolve Solana transaction atomicity in the one-violation incident path. It is a $0-first development plan, not a Mainnet commitment or a claim that the on-chain controls exist.
